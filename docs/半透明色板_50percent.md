# 半透明色板兼容表

计算日期：2026-09-06。

本表保留原有 63 个原色，并计算它们在 **50% 不透明度、底色 #F8F4F0** 下的显示色。
这是最初根据用户提供的 `#600018 → #AC7A84` 样本建立的兼容假设。
用户补充的以下三组实测对应关系也符合该配置，但尚未逐色实测当前插件，
也未直接验证插件内部的透明度和底色设置。其他透明度、背景或混色方式不保证适用。

逐 RGB 通道计算：`显示值 = (原值 + 底色值) / 2`。
表内显示色按四舍五入（半整数向上）列出。匹配器同时接受半整数向下/向上的取整组合；
如果某一通道结果本身是整数，则只接受该整数，未额外放宽全局颜色容差。
`ColorTol`、`IslandColorTol` 和选色容差仍只用于原色色板的近似匹配，不叠加到半透明显示色上，
以免把接近浅色显示值的背景识别成白色。

原色和显示色都归回同一个原色，再应用“想填/不想填”过滤；颜色管理仍然只有 63 个颜色。
全自动扫描、遗漏检测、颜色管理取色、白色样本判断及已取色判重共用该对应关系。
普通 A 键的两个采样色块继续显示真实采样 RGB，方便核对。
