Avalonia 精简工具栏样板
=====================

用途
验证像素风格、单行布局和交互手感，帮助决定是否迁移正式 UI。
独立项目，不连接正式程序，不读写原程序的设置或更新记录。
Avalonia 12.1.4 / .NET 10 / Windows x64。

运行
直接打开仓库内 publish\avalonia-toolbar-prototype\Wplace.ToolbarPrototype.exe。
它包含 .NET 运行时，无须单独安装 .NET。也可以运行本目录 Run-Prototype.ps1。
源码构建需要 .NET 10 SDK；脚本优先使用 artifacts\dotnet10 中的局部 SDK。
重新打包运行 Publish-Prototype.ps1。

本版可以体验
- 单行、方角、像素图标、蓝色选中态和按钮按下效果。
- 按住左侧六点拖动工具栏；右侧最小化、关闭。
- 所有主功能、色块、输入框、进度和时间均有说明浮窗。
- 两个色块单击切换示例；颜色管理中可切换想填/排除并勾选示例色。
- 步长支持输入、上下箭头和键盘上下键，范围 1–64。
- 平衡/极致模式；开始按钮播放 30/15 秒模拟任务。
- 遗漏检测播放 15 秒模拟任务。
- Esc 停止演示（样板窗口需要获得键盘焦点），无停止按钮。
- 运行时锁定参数修改；停止或完成后恢复。
- 矩形范围在独立的演示画布内拖选，扫描点受步长和眼睛按钮影响。
- 进度只显示百分比；时间和右侧按钮使用固定位置。
- 展开图标打开“样板预览面板”，可选 100/125/150% 预览倍率和进度示例。
- Tab / Shift+Tab 导航；键盘聚焦时也显示功能提示。

范围边界
本版的取色、扫描、填涂与耗时都是演示；不会点击外部应用或读取屏幕。
范围选择仅演示矩形，不代表多边形选择或桌面覆盖层已经迁移。
展开入口暂时用于预览面板，完整模式、更新说明、功能介绍尚未实现。
精简工具栏不包含 CPU 数量、停止、公告、GitHub、功能介绍按钮。
原程序没有 GPU 控件，本版未新增。
预览倍率调整不修改 Windows DPI；混合 DPI 多屏仍需正式集成后验证。

审阅导出
EXE --capture <绝对输出目录> [--exit-after-capture]
导出 0/9/62/100% 的工具栏渲染图、100/125/150% 比例图和布局坐标。
这些是 Avalonia 控件渲染结果，不是实机多屏 DPI 测试。

原项目隔离
主工程仅排除 prototypes 源码和 artifacts 缓存，业务逻辑未更改。
