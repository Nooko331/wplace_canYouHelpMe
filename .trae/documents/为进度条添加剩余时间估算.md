# 剩余时间估算功能实现方案

## 功能概述
为程序中的所有进度条（扫描、单次填充、全自动填充）增加剩余时间估算（ETA）显示。ETA 将以 `(mm:ss)` 格式显示在进度数值之后。

## 技术实现

### 1. 状态管理更新 (`RuntimeState.cs`)
- 新增 `ScanStartTime` 和 `AutoFillStartTime` 属性，用于记录操作开始时间。
- 新增 `StartScan(int total)` 方法，用于初始化扫描任务并记录开始时间。
- 更新 `Snapshot()` 方法，将时间戳传递给 UI 层。
- 更新 `StartAutoFill()` 方法，在启动时记录 `AutoFillStartTime`。

### 2. UI 逻辑更新 (`Form1.cs`)
- **辅助方法**: 添加 `GetEta(startTime, current, total)` 方法，根据已用时间和进度计算剩余时间。
- **UI 更新**: 修改 `UpdateUi` 方法，利用 `RuntimeState` 传递的时间戳计算 ETA，并追加到 `labelScanValue` 和 `labelMatchValue` 的文本中。
- **全自动填充**: 
    - 添加 `_autoFillAllStartTime` 字段记录全自动模式的开始时间。
    - 在 `ExecuteAutoFillAll` 开始时初始化该时间。
    - 更新 `UpdateAutoAllProgress` 方法，计算并显示 ETA。

### 3. 扫描逻辑增强
- 更新 `ScanMatchingPoints` 使用新的 `StartScan` 方法。
- 优化 `ScanMatchingPointsForAllColors`（全自动模式下的扫描），使其也能报告扫描进度和 ETA，提升用户体验。

## 验证计划
- 检查代码编译无误。
- 确认所有进度条逻辑均已覆盖。
- 确认时间计算逻辑处理了除零错误和初始状态。
